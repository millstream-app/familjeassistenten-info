Familjeassistenten · senast uppdaterad 3 november 2026

Vem appen är för

Familjeassistenten är en privat app som bara används av medlemmarna i en familj. Den körs på familjens egen server och är inte öppen för andra.

Vilka uppgifter appen läser från Google

Med ditt godkännande läser appen dina Google-kalendrar med endast läsbehörighet (calendar.readonly) samt din e-postadress för att veta vilket konto som är inloggat. Från kalendern används bara händelsernas titel, start- och sluttid. Appen kan inte skapa, ändra eller ta bort något i din kalender.

Hur uppgifterna används

Uppgifterna används enbart för att visa familjens kalender i appen och för att markera kvällar då det är mycket inbokat, så att middagsplaneringen kan anpassas.

Lagring och delning

  • Inloggningsnyckeln (token) lagras på familjens egen server, skyddad så att bara appen kan läsa den.
  • Kalenderhändelser sparas inte permanent, utan hämtas vid behov och hålls kortvarigt i minnet.
  • Uppgifterna säljs inte, delas inte med tredje part och används inte för reklam.

Användningen av information som tas emot från Googles API:er följer Google API Services User Data Policy, inklusive kraven på begränsad användning (Limited Use).

Återkalla åtkomst

Du kan när som helst ta bort appens åtkomst i ditt Google-konto under Tredjepartsappar och tjänster. Då slutar appen att kunna läsa din kalender.
